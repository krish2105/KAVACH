# Recall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let KAVACH answer "what did I do / say / decide" and "where is that thing" from its own history and from sources you name — with the source and timestamp attached to every answer, and a refusal when it has nothing.

**Architecture:** `MemoryStore` (sqlite-vec, already built) gets wired into `VoiceLoop`, which makes its existing write path live. `sources.py` adds one indexer per source type; `recall.py` turns a question into an answer carrying provenance, or into None. The router sends recall questions to it *before* the agent, the same shape as the clock patterns.

**Tech Stack:** Python 3.12 / uv, sqlite-vec, Ollama embeddings (`nomic-embed-text`), pytest.

## Global Constraints

- `permission_mode` stays `"default"`. Never auto-approve.
- The kill switch is evaluated first on every path.
- Every indexing run is logged to `~/.kavach/logs/actions.jsonl` with source and count.
- **Never index screen content or ambient audio.** Both stay cut.
- **No answer is ever synthesised from a weak match.** Below threshold → refuse.
- Turns and actions index automatically. Files, Messages and Mail index **only when named**.
- Indexing a new source is a **PROPOSE-tier** action (Phase 30).
- File reads go through `FileTools`, so the kill switch and the §7 log still apply.
- `VoiceState.as_dict()` stays field-identical to `KavachSnapshot`.
- Run tests with `uv run pytest` from `brain/`.
- Embeddings need Ollama running. `EmbeddingUnavailable` is raised when it is not — **never** swallow it into a silent no-op.

```python
"""What may be indexed, and what may never be.

**The line is passive versus asked.** Turns and actions are things KAVACH did
and already recorded — indexing them adds no new collection. Files, Messages
and Mail require you to name them.

**Screen content and ambient audio have no indexer here, deliberately.** The
user cut them as a privacy and storage liability, and §7 says wake-word audio
that was not acted on leaves no trace. A test asserts no such function exists,
so adding one has to be an argument rather than a discovery.

File reads go through `FileTools`, so the kill switch, the confirmation and
the §7 log all still apply — a second path to the disk would be a second gate
to keep in sync, which this project has now got wrong seven times.
"""

from __future__ import annotations

import json
import logging
from dataclasses import dataclass
from datetime import datetime

log = logging.getLogger("kavach.memory.sources")

#: Every source, and the collection it writes to. The collection is what
#: `MemoryStore.forget()` takes, so a source with none cannot be purged.
SOURCES = {
    "turns": "turns",
    "actions": "actions",
    "files": "files",
    "messages": "messages",
}


@dataclass
class Source:
    name: str
    collection: str


def _when(entry: dict) -> str:
    """A human timestamp for provenance. The event's own time, never now."""
    stamp = entry.get("ts")
    if not stamp:
        return "an unknown time"
    try:
        return datetime.fromisoformat(str(stamp)).strftime("%a %-d %b, %-I%p")
    except ValueError:
        return str(stamp)


def index_actions(store, action_log) -> int:
    """Index what KAVACH did. Returns how many rows were written."""
    written = 0
    for entry in action_log.read_all():
        event = entry.get("event", "")
        if not event.startswith(("action.", "file.", "tool.decision")):
            continue
        detail = {k: v for k, v in entry.items()
                  if k not in ("event", "ts") and isinstance(v, (str, int, float, bool))}
        text = f"On {_when(entry)} KAVACH did {event}: {json.dumps(detail)}"
        if store.remember(text, collection="actions",
                          source=f"action log, {_when(entry)}") is not None:
            written += 1
    return written


def index_file(store, tools, path: str) -> int:
    """Index one file's contents. Raises if it cannot be read.

    Raising rather than returning 0: zero-indexed and could-not-read look
    identical to a caller, and only one of them means the file was empty.
    """
    text = tools.read(path)
    written = store.remember(text, collection="files", source=f"file {path}")
    return 1 if written is not None else 0
```

CHI 2023 found voice-assistant abandonment is task-specific: one confident

    def __init__(self, results):
        self.results = results

def memory(text, source, score):
    return Memory(id=1, collection="actions", text=text, source=source,
                  created_at=0.0, score=score)


def test_a_strong_match_is_answered_with_its_source():
    store = FakeStore([memory("KAVACH opened Notes", "action log, Fri 8pm", 0.9)])

    answer = recall(store, "what did I open on Friday")

    assert answer is not None
    assert "Notes" in answer.text
    assert "action log" in answer.sources[0]


def test_a_weak_match_returns_nothing():
    """Not a hedged answer. Nothing. A confident wrong answer ends the task
    permanently; an honest miss does not."""
    store = FakeStore([memory("something unrelated", "action log", 0.05)])

    assert recall(store, "what did I open on Friday") is None


def test_an_empty_index_returns_nothing():
    assert recall(FakeStore([]), "anything") is None

    """A memory with no provenance cannot be checked, which is the same as
    not being trustworthy."""
    store = FakeStore([memory("x", "", 0.9), memory("y", "file /tmp/a", 0.9)])

    answer = recall(store, "q")

    assert all(s.strip() for s in answer.sources)

    """A threshold of zero means everything matches, which is the same as no

```python
"""A question becomes an answer with provenance, or it becomes nothing.

CHI 2023 on voice-assistant failures: abandonment is **task-specific**. One
truncated text message and the user never sends texts by voice again. A
confident wrong answer costs the task permanently; an honest miss does not.

So there is no hedged answer here. Above the threshold it answers and says
where from; below it, it returns None and the caller says "I don't have that".

**The model never sees a retrieved document without its provenance**, so it
cannot merge three sources into one unattributed claim.
"""

from __future__ import annotations

import logging
from dataclasses import dataclass, field

log = logging.getLogger("kavach.memory.recall")

#: Below this similarity, there is no answer. Deliberately not zero: a
#: threshold of zero matches everything, which is the same as no threshold.
MIN_SCORE = 0.35

#: How many memories to consider. Small on purpose — an answer assembled from
#: ten weak sources is the synthesis this module exists to prevent.
LIMIT = 5


@dataclass
class Answer:
    text: str
    sources: list[str] = field(default_factory=list)


def recall(store, question: str, min_score: float = MIN_SCORE) -> Answer | None:
    """Answer from memory, or None.

    None is the common case and the safe one. The caller must not turn it
    into a guess.
    """
    if not question or not question.strip():
        return None
    try:
        found = store.search(question, limit=LIMIT)
    except Exception:
        # Ollama down, or the index missing. Recall degrades to "I don't
        # have that", never to a broken turn.
        log.debug("recall search failed", exc_info=True)
        return None

    strong = [m for m in found if getattr(m, "score", 0.0) >= min_score]
    if not strong:
        return None

    return Answer(
        text="\n".join(m.text for m in strong),
        sources=[m.source for m in strong if (m.source or "").strip()],
    )
```
